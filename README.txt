撤离前线 | 3D 干员升级版

【单人】
双击 index.html，使用启用 WebGL 2 的新版 Chrome、Edge、Firefox 或 Safari。
选一张地图与职业，点击「开始游戏」。你和五名 AI 队友空手进图。

【好友联机】
1. 解压整个压缩包，房主使用 Node.js 18 或更高版本。无需单独安装游戏依赖。
2. Windows 双击 start-room-windows.bat。macOS / Linux 则打开终端，
   进入解压目录，运行 node room-server.cjs。
3. 房主在浏览器打开终端里显示的「局域网地址」，点「邀请好友」→「创建房间」。
4. 好友在同一局域网内打开房主分享的链接，填昵称后点「加入房间」。
   也可以先访问房主的局域网地址，再输入 6 位房间码。
5. 房主点「开始游戏」。小队固定六位，真人每多一位，AI 对应少一位。
6. 游戏中请保持房主终端开启。服务默认使用 8080 端口。
   如果 8080 已被占用，可运行 node room-server.cjs 8081，或在 Windows 终端
   运行 .\start-room-windows.bat 8081。以终端实际显示的地址为准。

房间链接要求好友能访问房主运行的服务器。这一版提供局域网房间，
没有公网匹配大厅。房主也应从局域网地址进入，确保邀请链接指向房主电脑。
如果终端列出多个地址，请使用当前 Wi-Fi 或有线网卡的地址。若好友无法访问，
请检查是否处在同一局域网，以及 Windows 专用网络防火墙是否允许 Node.js 入站。
双击 HTML 打开的是离线单机版。

【操作】
W A S D 或方向键移动，鼠标转向，Shift 冲刺，左键或「开火」按钮射击，
右键或 Q 瞄准，E 拾取物资或互动，R 换弹，H 使用急救包。
空格跳跃，C 蹲伏，Enter 也可开火。Esc 打开暂停菜单，可调视角灵敏度及音量。
触屏在左下方拖动摇杆移动，在右侧拖动画面转向。

【一局怎么玩】
1. 每局空手出发，随机捡枪和宝贝。捡到的枪立刻加入永久收藏。
2. 望明灯塔每张地图都有。按小地图上的标记，往塔南侧坡道走。
3. 中层平台上可以使用 64 倍望远镜。观察时无法移动，仍可能被击中。
4. 无论有没有枪，站在中层平台的信标圈内按 E，倒计时结束便成功撤离。
5. 系统自动进入商店，卖物资、攒信用点，购买随机定价的枪或刀。
   每把枪至少 1,000 信用点。购得的装备加入收藏，下一局仍空手出发。

【自创枪械】
M700  高射速冲锋枪，15 发一匣，试玩版暂定 3 秒换弹。
M571  远程冲锋枪，8 倍镜，30 发一匣，6 秒换弹。
M200  狙击步枪，32 倍镜。
M500  重型步枪，10 秒换弹。

【存档】
收藏、信用点及撤离次数保存在当前浏览器。使用其他浏览器、隐私窗口、
不同联机地址或不同文件路径时，浏览器可能使用独立存档。

游戏使用 Three.js 和 ws。3D 人物模型和动画的作者与许可见 CHARACTER-CREDITS.txt，
单机 HTML 也可从「设置 → 人物素材」查看。

【源文件】
GitHub 仓库中的 source 目录用于继续开发。进入该目录，运行 npm ci 和 npm run build，
可在 source/release 重新生成单机页面与房间服务器。npm test 运行联机回归测试。
